# Resume Agent Edit Middle Layer Design

## Goal
Provide a minimal front-end execution layer that applies AI agent “edit operations” to structured resume sections (blocks) using the existing `ResumeData` model. The agent runs on the backend and returns operations; the frontend applies them to local state and relies on existing auto-save.

## Architecture
The middle layer is a small, pure module that transforms `ResumeData` by applying a list of `ResumeEditOp`. It does **not** touch the rich-text editor or UI state directly. UI code calls the executor and then updates `useResume().updateResumeData`, so the existing react-hook-form and auto-save logic handle persistence. This keeps edits consistent with current front-end workflows and avoids backend state conflicts.

## Components
- **`ResumeEditOp` type**: operation list generated by the backend agent.
- **`applyResumeEditOps`**: pure function that applies ops to a `ResumeData` instance.
- **`Section helpers`**: optional utility to initialize missing optional sections for `addBlock`.

## Operation Spec (Minimal)
- `op`: `"addBlock" | "updateBlock" | "removeBlock"`
- `section`: `keyof ResumeData`
- `blockIndex`: number (optional for `addBlock`; default to append)
- `payload`:
  - `addBlock`: full block object for the target section
  - `updateBlock`: partial patch for that block
  - `removeBlock`: none

## Data Flow
Backend agent → returns `ResumeEditOp[]` → Frontend receives ops → `applyResumeEditOps(resumeData, ops)` → `useResume().updateResumeData(updated)` → existing auto-save persists changes.

## Error Handling
Executor should be non-throwing. It returns `{ updatedResumeData, appliedOps, errors }`. Errors include op index, code, and message (e.g., `SECTION_MISSING`, `INDEX_OUT_OF_RANGE`, `INVALID_PAYLOAD`). Invalid ops are skipped; valid ops are still applied.

## Testing
- Add/update/remove block happy paths
- Optional section auto-init on `addBlock`
- Index out-of-range and invalid payload handling

## Files (Proposed)
- Create: `lib/resume/agent-ops.ts` (types + executor)
- Optional: `lib/resume/section-helpers.ts`
- Tests: `lib/resume/agent-ops.test.ts`
