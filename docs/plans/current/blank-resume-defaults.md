# Blank Resume Start Flow

## 背景

当前空白简历的主路径已经从“自动塞入默认内容”转成了“空白画布 + 用户按需添加 section”。

这条路径更符合现在的产品判断：

- 不往 `resume_json` 里写示例经历
- 不用默认 block 冒充真实内容
- 用户自己决定需要哪些 section，再开始填写

因此，原先那份“给空白简历写默认值”的计划已经不再适合当前方向。

## 新目标

- 保持空白简历真正为空，不预填默认经历或技能内容
- 让用户进入编辑页后，能立刻理解下一步该做什么
- 让“添加 section -> 打开右侧表单 -> 开始填写”成为稳定主路径
- 继续完善空白简历从 0 到 1 的可发现性和可编辑性

## 非目标

- 不为 `education`、`employment`、`skills` 自动创建默认 block
- 不在数据层写入示例姓名、学校、公司或技能
- 不把“默认值”作为空白简历体验的主要解法

## 当前状态

已经完成：

- 空白简历语言可基于创建时传入的 `language`
- 空白简历只保留最小必要结构，不再默认展开全部 optional section
- 左侧画布支持空白页中心 `Add Section` 入口
- 非空简历支持底部 `Add Section` 入口
- optional section 已支持从画布添加并打开右侧对应表单
- 已创建但仍为空的 optional section 仍可从菜单重新进入

仍可继续优化：

- 空白简历首次进入时，右侧默认仍可能停留在 `evaluation`
- 部分表单提示文案和 placeholder 仍然偏少
- required section 在空状态下的引导仍可更清晰
- “先选 section，再填写内容”的心智还可以进一步压缩步骤

## 设计原则

- 空白就是空白，不伪造内容
- 起步动作要明显，但不要打扰已经开始编辑的用户
- 入口应尽量贴近简历画布，而不是藏在侧边配置里
- 已创建但暂无内容的 section 不能变成“不可返回”的死状态
- 文案提示优先放在 UI 层，不把引导文本写进简历数据

## 建议方案

### 1. 保持数据层极简

空白简历仍保持当前策略：

- `personalInfo` 字段为空
- required section 保留结构
- optional section 按需创建
- 不写默认 block

如果后续需要更强引导，应优先通过 UI 提示解决，而不是数据预填。

### 2. 强化空白态引导

围绕空白页入口继续优化：

- 中心按钮文案保持直接清晰
- 弹层内优先展示最常见起步项
- 选中后立即切到对应表单
- 如果用户切走，仍能从画布入口重新进入空 section

### 3. 补足表单层引导

把“默认值计划”转成“表单引导计划”，重点是：

- 为 `personal-info-form.tsx` 增加 placeholder
- 为 `education-form.tsx` 增加 placeholder
- 为 `employment-form.tsx` 增加 placeholder
- 为 `skills-form.tsx` 增加 placeholder
- 对新增 optional section 的表单增加基础提示文案

这些文案必须走 `en/zh` 双语，不直接写入简历数据。

### 4. 优化空 section 的返回入口

保持并完善当前能力：

- 已添加但空的 optional section 应继续出现在入口菜单中
- 必要时可补一个更明确的“Continue Editing”语义
- 如果后续支持 required section 空态点击，也应保持一致交互

### 5. 评估右侧默认视图

可进一步判断是否要在“空白简历首次打开”时默认进入 `form` 视图，而不是 `evaluation`。

这个优化的价值是：

- 降低第一次进入编辑页时的理解成本
- 让空白简历更像“开始写”，而不是“先看报告”

是否实施可以单独评估，不强绑在当前阶段。

## 实施步骤

### Phase 1: 文案与引导

- 为核心表单补 placeholder 和提示文案
- 文案接入 `en/zh` 翻译
- 避免继续新增硬编码英文提示

### Phase 2: 空白简历首屏优化

- 评估右侧默认视图是否切换为更适合起步的状态
- 继续收紧空白态和非空态的入口体验
- 确保空 section 可重复进入

### Phase 3: 回归验证

- 检查空白简历创建流程
- 检查从空白页添加 section 的主路径
- 检查切换 section 后能否重新进入空 section
- 使用 Playwright 对关键路径做回归

## 验收标准

- 创建空白简历后，用户能清楚看到下一步入口
- 用户无需依赖默认示例内容，也能顺利开始填写
- 已添加但未填写内容的 section 可以重新打开
- 核心表单具备清晰 placeholder 和双语文案
- 空白简历主流程在 Playwright 回归中稳定可用

## 预期结果

这份计划完成后，空白简历体验将不再依赖“默认值”来降低门槛，而是通过更清晰的画布入口、稳定的 section 返回机制和更好的表单引导，让用户自然开始填写自己的内容。
