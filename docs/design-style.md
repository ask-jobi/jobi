# 设计风格指南

本文档总结当前 Jobi 项目已经形成的设计风格。后续新增页面、组件和交互时，应优先复用并延续这些模式，避免单点页面视觉语言漂移。

## 设计基调

- 整体气质是 `专业、克制、轻量、可信`，优先服务于求职和简历场景，不做强娱乐化表达
- 主应用区偏 `工具型产品`，以稳定、清晰、低干扰为第一优先级
- 营销页和关键转化区允许比工作台更强的视觉表达，但仍然保持简洁，不走夸张炫技路线
- 页面信息密度适中，依靠留白、边框、阴影和层级来组织内容，而不是依赖高饱和色块

## 色彩体系

### 基础色

- 以中性色系统为主，基础背景使用 `background / card / muted / border` 等 token
- 默认浅色主题是主场景，整体呈现白底、浅灰边框、深灰文字
- 深色主题 token 已存在，但新增界面仍应先保证浅色主题观感完整，再检查深色兼容

### 强调色

- 通用组件层的主色仍以 token 驱动的 `primary` 为准，不要在业务组件里随意重定义整套配色
- 首页 Hero、核心 CTA 可以使用 `紫 -> 蓝` 的渐变强化品牌感
- 成功状态使用绿色点缀，危险状态使用 destructive 红色
- 除营销页 CTA 外，不要大面积堆叠高饱和渐变

## 字体与文案观感

- 全局主字体使用 `Geist Sans`，代码或技术型内容使用 `Geist Mono`
- 中文补充字体已接入 `SourceHanSansSC`，新增设计应保证中英文混排自然，不要引入风格冲突明显的新字体
- 标题风格偏简洁有力，常见为 `font-semibold` 或 `font-bold`
- 正文说明文字多使用 `text-muted-foreground`，语气清晰直接，避免过度营销化措辞

## 布局原则

- 营销页采用 `container + 居中 + 大块留白`，常见节奏是 `py-20`、`py-24`、`py-32`
- 工作台采用 `sidebar + content` 的经典工具布局，内容区域优先保证可滚动、可扫描、可连续工作
- 卡片栅格是重要布局母题，常见于 dashboard、功能分组、定价区、问题说明区
- 表单、弹窗、侧栏都采用较规整的间距系统，优先使用现有 spacing，不要出现非常跳的局部间距

## 形状与层级

- 基础圆角以 `rounded-md`、`rounded-xl` 为主，整体偏柔和，但不过度圆润
- 常规层级通过 `border + shadow-sm/shadow-lg` 建立，不依赖复杂拟物
- 卡片是最常见的信息容器，默认白底、浅边框、轻阴影
- Hover 态允许轻微放大、提亮阴影或边框强化，但幅度要小，保持稳重

## 组件风格

### Button

- 默认按钮走系统化样式，优先复用 `components/ui/button.tsx`
- 主要操作使用实心按钮，次要操作使用 `outline` 或 `ghost`
- 强营销按钮可在局部增加渐变、光晕、扫光，但应只用于首屏 CTA 或关键转化点

### Card

- 优先使用统一 Card 体系承载内容
- 内容结构通常是 `标题 + 描述 + 操作` 或 `预览 + 悬浮操作`
- 卡片内部尽量保持干净，避免同时出现过多强调色、边框样式和装饰元素

### Input / Form

- 输入框风格是浅边框、透明或浅底、聚焦 ring 明确
- 表单界面以清晰、稳定为先，不做复杂背景和过强视觉修饰
- 校验、禁用、危险态统一使用系统 token，不新增自定义状态颜色

### Sidebar / Dialog / Tooltip

- 导航、弹窗、提示等结构优先复用现有 shadcn/Radix 封装
- 这些组件的视觉应偏系统级、安静、可预期，不要做强品牌装饰

## 动效原则

- 当前项目允许使用 `淡入、平移进入、轻微缩放、阴影增强、shimmer/pulse` 等轻量动效
- 动效主要用于 `首屏叙事、卡片进入、加载反馈、CTA 强化`
- 动效时长通常在 `200ms - 700ms` 范围内，避免拖沓
- 不要同时叠加太多持续性动画，避免页面显得躁动

## 页面类型的风格边界

### 营销页

- 可以使用背景渐变、标题渐变文字、CTA 光效、滚动进入动画
- 允许更强的视觉叙事，但仍要维持简洁版式和明确转化路径

### 工作台 / Dashboard

- 以效率优先，强调卡片化、网格化、低干扰
- 背景和容器保持克制，重点通过内容本身而不是装饰来建立层级

### 编辑器 / 简历工作区 / Chat

- 这是高频使用区域，风格应最稳定、最少噪音
- 优先保证阅读、输入、对比、侧栏协作等任务流顺畅
- 除必要操作反馈外，避免加入营销式渐变和大幅装饰

## 新设计开发时的 Do

- 优先复用现有 token、基础组件和已存在的卡片/表单/侧栏模式
- 先判断页面属于营销页还是工作台，再决定视觉强度
- 用留白、字号、字重和浅层阴影建立层级
- 让主操作清晰突出，但控制页面中“强强调元素”的数量
- 新增样式时优先抽象为可复用模式，而不是只服务单个页面

## 新设计开发时的 Don't

- 不要在不同页面随意切换完全不同的配色体系
- 不要引入新的高辨识度视觉语言破坏现有克制感，例如重玻璃拟态、重霓虹、重插画背景
- 不要在工作台页面大面积使用首页那种品牌渐变按钮和持续光效
- 不要为了“更设计感”牺牲信息清晰度、可点击性和表单可用性
- 不要脱离现有 `ui` 组件体系重复造一套相似但不兼容的基础组件

## 一句话原则

Jobi 的界面风格应始终保持：`求职工具产品的专业可信感` 为底，`在关键转化点适度加入品牌感和动效`，但不牺牲整体的一致性、清晰度与可操作性。
